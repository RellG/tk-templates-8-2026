# tk-templates-8-2026

Landing page templates generated from extracted design systems and design tokens.

## Features

- Scrapes design systems and extracts semantic tokens (colors, typography, spacing, radius).
- Builds landing-page templates styled with each system's tokens.
- Interactive template gallery in `./site`.

## Usage

```bash
# Install dependencies
npm install

# Build templates
node build-templates.js

# Serve preview gallery
node serve.js
```
